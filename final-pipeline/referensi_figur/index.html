Referensi figur paper

Dibuat dari README.md (sumber kebenaran). Gambar di img/ tidak di-commit.

Training

Dataset Cartography, Swayamdipta dkk. 2020, 2009.10795 Gbr. 1

Data map: titik per contoh, x = variabilitas, y = keyakinan ke label benar, warna = proporsi epoch benar; zona easy/ambiguous/hard

Versi kita: Data map fine-tune IndoBERT + 3 contoh teks per zona · butuh: prob per epoch per contoh latih

Example Forgetting, Toneva dkk. 2019, 1812.05159

Heatmap jumlah "lupa" vs margin; grid contoh tak-pernah-lupa vs sering-lupa; stabilitas peringkat antar seed

Versi kita: Tabel/grid teks "selalu benar" vs "bolak-balik" · butuh: prediksi per epoch

How to Fine-Tune BERT, Sun dkk. 2019, 1905.05583

Kurva error train vs dev per iterasi; lr 4e-4 gagal total (error 0,5)

Versi kita: Kurva loss/F1 train vs val per epoch, dua lr berdampingan · butuh: log per epoch/step

Revisiting Few-sample BERT, Zhang dkk. 2021, 2006.05987

Heatmap skor seed-init x seed-data

Versi kita: Sebaran F1 antar fold/seed (strip/box) untuk tiap model · butuh: skor per fold

Scaling Laws, Kaplan dkk. 2020, 2001.08361

Kurva loss vs step, warna = ukuran data/model; train putus-putus vs test

Versi kita: Kurva belajar: F1 vs % data latih (25/50/75/100) untuk TF-IDF dan IndoBERT · butuh: latih ulang di subset

Deep Double Descent, Nakkiran dkk. 2019, 1912.02292

Heatmap error test (epoch x ukuran model); kurva NLP data kecil vs besar

Versi kita: Heatmap F1 (epoch x lr) atau (epoch x max_len) · butuh: grid kecil

IndoNLU, Wilie dkk. 2020, 2009.05387

Bubble: F1 vs jumlah parameter (log), gelembung = biaya, label langsung

Versi kita: Pengganti `02_model`: F1 vs waktu latih/inferensi per model · butuh: skor + waktu per model

Evaluasi / keandalan

On Calibration, Guo dkk. 2017, 1706.04599 Gbr. 1

Atas: histogram keyakinan + garis rata-rata; bawah: reliability diagram dengan celah merah, teks "Error="

Versi kita: Upgrade `05_keandalan`: TF-IDF vs IndoBERT berdampingan + ECE · butuh: prob OOF

LMs (Mostly) Know What They Know, Kadavath dkk. 2022, 2207.05221

Kurva kalibrasi diwarnai ukuran model; token diwarnai skor

Versi kita: Teks contoh dengan kata diwarnai bobot (koef TF-IDF/atribusi) · butuh: koef model linear

Pervasive Label Errors, Northcutt dkk. 2021, 2103.14749

Grid contoh: label diberi vs label koreksi, per dataset

Versi kita: Grid teks: label asli vs prediksi yakin (calon salah label) · butuh: prob OOF

Shortcut Learning, Geirhos dkk. 2020, 2004.07780

Diagram konsep rapi: train vs i.i.d. vs o.o.d.

Versi kita: Diagram kebocoran (mis. urutan baris memprediksi label) · butuh: -

Kurva sebaran panjang teks per kelas

Versi kita: Ganti panel skor kolom di `01_data` dengan KDE panjang per kelas + kata pemicu per kelas · butuh: data latih

NusaX, Winata dkk. 2023, 2205.15960

Heatmap train x test; heatmap irisan kosakata antar bahasa (angka di sel)

Versi kita: Heatmap irisan kosakata antar kelas/topik, atau train vs test · butuh: data latih/uji
